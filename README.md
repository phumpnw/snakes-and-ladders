# บันไดงู รู้สิทธิ

เกมบันไดงูบนเว็บสำหรับเรียนรู้สิทธิและสวัสดิการสังคม เล่นได้ 1–4 คนบนเครื่องเดียว กระดานสุ่มใหม่ทุกเกม

## วิธีเล่น
- ก่อนเริ่ม ผู้เล่นแต่ละคนเลือก **เพศ** และ **ช่วงอายุ** (ใช้เลือกรูปตัวละคร เลือกเรื่องบนกระดานให้เหมาะกับวัย และเก็บสถิติตามกลุ่ม)
- ทุกเกมสุ่มตำแหน่งบันได/งู และสุ่มสถานการณ์ 8 บันได + 8 งู จากคลังทั้งหมด
- ตกช่อง **บันได** หรือ **งู** จะเจอ **สถานการณ์** ให้เลือกวิธีรับมือ
  - ช่องบันได: ตอบถูก ได้ขึ้นบันได
  - ช่องงู: ตอบถูก รอดจากงู / ตอบผิด ไถลลง
- หลังตอบ จะเห็น **วิธีแก้ เหตุผล/สิทธิที่เกี่ยวข้อง และสายด่วน**
- ตกช่องว่าง จะได้อ่านความรู้ **"รู้หรือไม่"** และชี้หรือแตะช่องไหนบนกระดานก็ได้เพื่ออ่านความรู้ของช่องนั้น
- เมื่อมีคนถึงช่อง 100 ทุกคนตอบ **คำถามท้ายบท** คนละ 3 ข้อ (เลือกจากหมวดที่เจอในเกม)
- ดู **สรุปผลและสถิติ** ของเกม สถิติสะสมของเครื่องนี้ และ **สมุดสิทธิ** ที่ปลดล็อกได้
- มีเพลงพื้นหลัง เสียงเอฟเฟกต์ และเอฟเฟกต์ภาพ ปุ่มมุมขวาล่างใช้เปิด/ปิดเพลง เปิด/ปิดเสียงเอฟเฟกต์ และเล่นแบบเต็มจอ

## เปิดเกม
รันเซิร์ฟเวอร์ในเครื่อง:

```
python -m http.server 8765
```

แล้วเข้า http://localhost:8765

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `data.js` | เนื้อหาทั้งหมด: สถานการณ์ (`SCENARIOS` พร้อมกลุ่มอายุ `ages`), คำถามท้ายบท (`QUIZ`), ความรู้ช่องว่าง (`TIPS`), กลุ่มอายุ/เพศ |
| `game.js` | กลไกเกม สถิติ คำถามท้ายบท |
| `sfx.js` | เสียงเอฟเฟกต์ (สังเคราะห์ด้วย Web Audio ไม่ใช้ไฟล์เสียง) |
| `music.js` | เพลงพื้นหลัง สร้างสดด้วย Web Audio ทำนองสุ่มใหม่เรื่อย ๆ (ไม่มีไฟล์เพลง ไม่มีปัญหาลิขสิทธิ์) |
| `analytics.js` | ส่งสถิติแบบไม่ระบุตัวตนไป Google Sheets (ปิดอยู่จนกว่าจะใส่ `ANALYTICS_URL`) |
| `analytics/apps-script.gs` | โค้ด Apps Script สำหรับรับข้อมูลลงชีตและสร้างหน้าสรุป |
| `fx.js` | เอฟเฟกต์ภาพ: พลุกระดาษ ประกาย กระดานสั่น |
| `icons.js` | ไอคอนรูปภาพ (มี SVG สำรองถ้าโหลดรูปไม่ได้) |
| `assets/` | รูปทั้งหมดสร้างด้วย Codex: `avatars/` ตัวละคร 12 แบบ (4 ช่วงอายุ × 3 เพศ), `icons/` ไอคอน 18 แบบ, `decor/` ภาพประกอบหมวดสิทธิ ฉากหลัง และแผนที่กระดาน |

## เก็บสถิติผู้เล่นด้วย Google Sheets

เกมส่งข้อมูลแบบ **ไม่ระบุตัวตน** (ไม่มีชื่อผู้เล่น ไม่มี IP) ไปที่ Google Sheet ของคุณ:
- **Starts**: เกมที่เริ่มเล่น (จำนวนผู้เล่น ช่วงอายุ เพศ)
- **Answers**: ทุกคำตอบ (สถานการณ์/ท้ายบท หมวด ช่วงอายุ เพศ ถูกหรือผิด)
- **Results**: ผลจบเกมของผู้เล่นแต่ละคน (คะแนน ตอบถูก บันได งู ความรู้ที่อ่าน เวลาเล่น)
- **Summary**: หน้าสรุปอัตโนมัติ: จำนวนเกม อัตราเล่นจบ % ตอบถูกตามหมวด/อายุ/เพศ และเรื่องที่คนตอบผิดบ่อยที่สุด

### ติดตั้ง (ทำครั้งเดียว ประมาณ 5 นาที)
1. สร้าง Google Sheet ใหม่ที่ [sheets.new](https://sheets.new)
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `analytics/apps-script.gs` → กดบันทึก
3. เลือกฟังก์ชัน **setup** ที่แถบด้านบน แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ (Google จะเตือนว่าแอปยังไม่ได้รับการยืนยัน ให้กด "ขั้นสูง" → "ไปที่ ... (ไม่ปลอดภัย)" เพราะเป็นสคริปต์ของคุณเอง)
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → เลือกประเภท **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
6. วาง URL ใน `analytics.js` ที่ `const ANALYTICS_URL = "..."` แล้ว commit + push

เมื่อเปิดใช้แล้ว หน้าแรกของเกมจะแสดงข้อความแจ้งผู้เล่นว่าเก็บสถิติแบบไม่ระบุตัวตน

> หมายเหตุ: ใครที่รู้ URL ของเว็บแอปก็ส่งข้อมูลปลอมเข้ามาได้ จึงเหมาะกับการดูแนวโน้ม ไม่ใช่ข้อมูลที่ต้องแม่นยำ 100%

> ข้อมูลสิทธิและสายด่วนอาจเปลี่ยนแปลงได้ ควรตรวจสอบกับหน่วยงานที่เกี่ยวข้องก่อนนำไปใช้จริง
